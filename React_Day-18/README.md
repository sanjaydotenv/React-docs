# 📖 About The Project

This project is a modern **E-Commerce Store** developed using **React.js** and **Tailwind CSS**.

The application is built completely from scratch using a custom product collection without relying on external product APIs. It demonstrates real-world React development concepts including reusable components, Context API, custom hooks, LocalStorage, search functionality, category filtering, shopping cart management, and responsive UI design.

The project focuses on writing clean, scalable, and maintainable code while creating a smooth shopping experience.
